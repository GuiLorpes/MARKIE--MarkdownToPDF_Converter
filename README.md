# MARKIE -- The Markdown to PDF Converter!

MARKIE is a project that is used to convert any markdown file into a PDF file.

MARKIE was made with the intention to write articles, class notes, slides, or any kind of work into the format that you want. Since it uses an Markdown to HTML to PDF aproach, you can customize the final product any way you like, it comes with a collection of pre-made styles with a base style, a SBC Article style and a base slide style, along with the styles for a Table of Contents and a dark theme
